# COBBLEVERSE 친구용 런처

친구 서버용 Minecraft Java Edition 런처 배포 페이지입니다.

## 설치 방법
1. [최신 릴리스](https://github.com/bagm1163-ai/cobbleverse-friends-launcher/releases/latest)에서 `COBBLEVERSE Launcher.exe` 파일을 다운로드합니다.
2. Windows 10/11 64비트에서 파일을 실행합니다.
3. 런처에서 **① 마인크래프트 계정 로그인** 버튼을 누르고 공식 Microsoft 계정 로그인 화면에서 Minecraft Java Edition 계정으로 로그인합니다.
4. **② COBBLEVERSE 게임 실행** 버튼을 누르면 모드팩과 리소스팩을 내려받고 게임이 실행됩니다.
5. 서버 운영자에게 안내받은 주소로 접속합니다.

**주의:** 서버 운영자 PC가 꺼져 있으면 업데이트 다운로드에 실패할 수 있습니다. 계정 암호는 타인에게 보내지 마세요. 코드서명 인증서가 없는 실행 파일이므로 Windows SmartScreen 경고가 표시될 수 있습니다.

본 저장소에는 단일 런처 실행 파일만 배포하며, Minecraft 및 포함된 모드의 권리는 각 제작자에게 있습니다.
